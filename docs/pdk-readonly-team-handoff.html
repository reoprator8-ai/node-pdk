PDK Read-only MCP Package

Developer handoff and installation guide
Purpose: Connect Claude to PDK through a local MCP server for authenticated, read-only searches and event queries. No credentials are placed in chat, source control, the Claude JSON file, or the package archive.

Install for a developer

From the folder containing the tarball:

npm install --global .\pdk-client-0.8.0.tgz
New-Item -ItemType Directory -Force "$HOME\.pdk" | Out-Null
Set-Location "$HOME\.pdk"
pdk-setup

pdk-setup prompts locally for the PDK OAuth client ID and client secret, then writes an ignored .env file in the current folder. Each developer should use an approved, rotated credential.

Connect Claude Desktop

Copy the JSON template into Claude Desktop's MCP configuration, replace YOUR-NAME, and restart Claude Desktop:

{
  "mcpServers": {
    "pdk-readonly": {
      "command": "pdk-mcp",
      "cwd": "C:\\Users\\YOUR-NAME\\.pdk"
    }
  }
}

The cwd points to the folder containing the local .env. The JSON contains no secret.

Read-only tools

  • getPanel — fetch panel details.
  • listEntities — search people, doors, sites, groups, and credentials with pagination.
  • getEntity — fetch one entity.
  • getGroupMembers — read group membership.
  • listPersonCards — read cards assigned to a person.
  • getEventStream — collect bounded live events.

Not available: creating or deleting people, adding cards, assigning groups, sending commands, unlocking doors, or changing configuration.

Direct sanitized triage lookup

pdk-triage --panel 1072FW4 --entity persons --search "Groups Issue" --output report.json

The report records duration, query, pagination, and results. Sensitive fields such as tokens, secrets, authorization values, credentials, and card numbers are replaced with [REDACTED].

Operational notes

  • Node.js 18 or newer is required.
  • Authentication is still required, but it is entered locally once per workstation.
  • Do not send secrets through chat or commit .env.
  • For changes, update the source repository, run lint, then rebuild with npm pack.
